## ⚠️ 먼저 확인해 주세요

**api·ui 이미지를 반드시 함께 받아 주세요.** API 문서 화면이 이번에 이미지 안에서 자체 제공되도록 바뀌어서, 한쪽만 올리면 그 화면이 빈 페이지로 보입니다.

## 새 기능

- **프록시 호스트에 태그를 달 수 있습니다.** 호스트 편집 화면 기본 탭에서 `media`·`family`·`prod` 같은 라벨을 호스트당 최대 10개까지.
- **목록을 태그·도메인·업스트림·상태로 좁혀 봅니다.** 태그를 여러 개 고르면 그 태그를 모두 가진 호스트만 남습니다.
- **행에 보이는 태그를 누르면 바로 그 태그로 필터가 걸립니다.** 필터는 주소에 남아서 자주 쓰는 조합을 북마크하거나 링크로 공유할 수 있습니다.
- 태그는 백업에 함께 담기고 복원 시 그대로 돌아옵니다.

## 고침

- **1MB보다 큰 백업 파일을 복원할 수 없던 문제.** 관리 화면의 업로드가 1MB에서 막혀 있어서, 서버를 옮기며 백업을 복원하려던 경우 실패했습니다. 한도를 100MB로 올렸고, 한도를 넘었을 때는 그렇다고 알려 줍니다.
- **API 문서(`/api/docs`) 화면이 비어 보이던 문제.** 이제 외부 인터넷 연결 없이도 열립니다.
- **관리 화면의 정적 파일에 보안 헤더가 빠져 있던 문제.**

## 그 밖에

새로 설치하는 경우에만 해당하던 로그 테이블의 컬럼 타입 차이를 맞췄습니다. 기존 설치는 영향이 없습니다.

> ```

## ⚠️ Read first

**Pull both the api and ui images.** The API documentation page is now served from inside the image, so upgrading only one of them leaves that page blank.

## New

- **Tag your proxy hosts.** Up to 10 free-form labels per host — `media`, `family`, `prod` — on the Basic tab of the host form.
- **Narrow the list by tag, parent domain, upstream or status.** Pick several tags and only the hosts carrying all of them stay.
- **Click a tag on a row to filter by it.** The filter stays in the address bar, so a view you use often can be bookmarked or shared.
- Tags travel with your backups and come back on restore.

## Fixed

- **Backup archives larger than 1 MB could not be restored.** The admin panel's upload stopped at 1 MB, so restoring a backup while moving to a new server failed. The limit is now 100 MB, and an archive over it says so.
- **The API documentation page (`/api/docs`) rendered blank.** It now opens without any outside internet access.
- **Static files in the admin panel were served without their security headers.**

## Also

A column type in the logs table that only differed on brand-new installs now matches. Existing installs are unaffected.
