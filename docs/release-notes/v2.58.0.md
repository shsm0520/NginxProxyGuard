## ⚠️ 먼저 확인해 주세요

**api·ui 이미지를 반드시 함께 받아 주세요.** 2단계 인증의 백업 코드가 이번에 다른 시점에 발급되도록 바뀌어서, 한쪽만 올리면 등록을 마친 뒤 백업 코드 화면이 비어 보입니다. 아래 명령은 둘 다 받습니다.

## 2단계 인증

- **등록할 때 올바른 코드가 "올바르지 않다"고 나오던 문제.** 설정 화면을 닫았다가 다시 열면 이미 스캔해 둔 QR이 조용히 무효가 되고 있었습니다. 인증 앱이 무엇이든 전부 거부됐고, 틀린 코드와 메시지가 같아서 알아챌 방법도 없었습니다.
- **백업 코드를 로그인 화면에서 입력할 수 없던 문제.** 입력칸이 글자를 지우고 6자로 잘라내서, 8자짜리 백업 코드는 아예 들어가지 않았습니다. 인증 앱을 잃으면 초기화 말고는 방법이 없었습니다.
- **이제 백업 코드로 2단계 인증을 끌 수도 있습니다.** 전에는 백업 코드로 들어올 수는 있어도 끌 수는 없어서, 새 기기로 다시 등록하려면 없어진 기기의 코드가 필요했습니다.
- `123 456`처럼 공백이 섞여 붙여넣어져도 인식합니다.
- 2단계 인증 화면 제목이 "비밀번호 변경"으로 표시되던 문제.
- 거부된 인증 시도가 감사 로그에 남습니다.

## 그 밖의 고침

- **인증서가 삭제되지 않는데 "연결된 호스트"는 비어 보이던 문제.** 리다이렉트 호스트가 목록에서 빠져 있었고, 프록시 호스트도 앞의 20개만 보고 있었습니다. 삭제가 거부되면 이유도 화면에 표시됩니다.
- **로그 "지금 회전"이 하루 중 두 번째부터 실패하던 문제.** 회전할 내용이 없어 건너뛴 경우에도 "완료"라고 표시되던 것도 함께 고쳤습니다.
- 잘못된 ID로 요청했을 때 데이터베이스 내부 오류 문구가 그대로 보이던 문제. 저장돼 있다가 나중에 다시 표시되던 것도 같이 정리했습니다.
- 목록을 한 번에 20개보다 많이 요청하면 오히려 20개로 줄어들던 문제.

## 업그레이드가 하는 일

신규 설치에만 있던 로그 테이블의 컬럼 타입 차이를, 가능한 경우 기동 중에 자동으로 맞춥니다. 로그가 이미 압축된 설치는 그대로 두고 넘어갑니다.

## ⚠️ Read first

**Pull both the api and ui images.** Two-factor backup codes are now issued at a different point, so upgrading only one of them leaves the backup-code screen empty after you finish enrolling. The command below pulls both.

## Two-factor authentication

- **Enrolment rejected codes that were correct.** Closing the setup dialog and re-opening it silently invalidated the QR you had already scanned, so every authenticator was refused — with the same message a wrong code gets, and nothing to say why.
- **Backup codes could not be typed on the login screen.** The field stripped letters and cut the value to six characters, so an 8-character backup code never reached the server. If your authenticator was gone, resetting 2FA was the only way back in.
- **A backup code can now also turn 2FA off.** It used to get you in but not out, so re-pairing a new device needed a code from the device you no longer had.
- Codes pasted with spacing, like `123 456`, are accepted.
- The 2FA screen was titled "Change password".
- Rejected attempts are now recorded in the audit log.

## Also fixed

- **A certificate refused to delete while its "Linked hosts" column looked empty.** Redirect hosts were missing from that list, and proxy hosts were only counted up to the first twenty. A refused delete now says why.
- **"Rotate now" failed for the rest of the day after the first rotation.** A rotation that was skipped because there was nothing to cut also reported success.
- Malformed identifiers returned raw database error text — in responses, and in stored messages replayed later.
- Asking a list for more than 20 items at a time returned 20.

## What the upgrade does

Where it can, it corrects a log-table column type that only differed on brand-new installs. Installs whose logs are already compressed are left alone.
